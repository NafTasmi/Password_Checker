# Password Checker Analyzer

A modern, secure password strength analyzer built with Python and CustomTkinter. This application evaluates password security and provides real-time feedback with visual indicators.


## Features

- 🔒 **Real-time Password Strength Analysis**
- 📊 **Visual Strength Indicator** (Progress Bar)
- 👁️ **Show/Hide Password Toggle**
- 💡 **Smart Password Suggestions**
- 🔐 **Secure Password Hashing** (SHA-256)
- 💾 **Optional Secure Storage**
- 🎨 **Modern Dark Theme UI**

### Prerequisites
- Python 3.6 or higher
- pip (Python package manager)

pip install customtkinter
